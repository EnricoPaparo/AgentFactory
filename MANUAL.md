# Manuale AgentFactory

Questo manuale documenta il percorso personale per diventare capace di progettare e costruire sistemi multi-agent professionali.

Non e' un archivio di appunti. E' il sistema di apprendimento e memoria del percorso.

## Visione

Una Agent Factory e' un sistema capace di:

1. ricevere un progetto o problema;
2. capire quali agenti servono;
3. creare o configurare agenti specializzati;
4. assegnare contesto, tool e privilegi;
5. orchestrare il lavoro;
6. produrre artefatti verificabili;
7. valutare risultati;
8. riassorbire conoscenza utile;
9. migliorare agenti, template e regole nel tempo.

## Regola di ogni lezione

Ogni lezione deve essere dettagliata, spiegata e motivata. Non deve limitarsi a una lista di definizioni.

Ogni lezione deve includere:

- obiettivo;
- perche' conta;
- prerequisiti;
- spiegazione dettagliata;
- esempio semplice;
- esempio professionale;
- anti-pattern ed errori comuni;
- collegamento con AgentFactory;
- verifica personale.

Ogni lezione deve chiudersi con:

- cosa ho imparato;
- artefatto prodotto;
- template eventualmente aggiornato;
- conoscenza da assorbire;
- prossimo passo.

## Stato

Il manuale e' stato riportato a una base minima. Le lezioni precedenti sono state rimosse per ripartire con un percorso piu' graduale e piu' adatto all'obiettivo: diventare forte nella progettazione di sistemi agentici, non accumulare teoria scollegata.
