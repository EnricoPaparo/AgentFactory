Stato del progetto

Base statica pronta. Nuove lezioni in arrivo.

Il sito è stato ripulito per mantenere solo la struttura web. Le vecchie lezioni sono state rimosse: il prossimo percorso verrà inserito come contenuto nuovo, più ordinato e più utile.

Focus: trasformare AgentFactory in un manuale pratico, progressivo e pubblicabile, senza rumore e senza materiale obsoleto.

Percorso

Cosa diventerà AgentFactory

01

Fondamenta operative

Prompt, artefatti, template, Agent Card, output contract e regole minime per lavorare con agenti in modo verificabile.

02

Workflow multi-agent

Come collegare ruoli diversi: analyst, architect, developer, tester, reviewer e supervisor, con handoff chiari.

03

Runtime e governance

Esecuzioni controllate, privilegi, budget, API key, run record, review, rollback e miglioramento continuo.

Metodo

Non solo teoria: ogni lezione deve produrre qualcosa.

Il nuovo sito sarà costruito attorno a risultati concreti: una lezione deve lasciare un template, una checklist, una regola, una decisione o un esperimento riutilizzabile.

Artefatti verificabiliOgni output deve poter essere letto, revisionato e versionato.
Progressione controllataSi passa allo step successivo solo quando lo step precedente è chiaro.
Human gateLe decisioni rischiose restano sotto controllo umano.
Memoria utileSolo la conoscenza validata entra nella factory.
