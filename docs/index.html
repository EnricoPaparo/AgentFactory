Obiettivo

Da zero a progettazione agentica professionale

AgentFactory e' un manuale operativo e un laboratorio reale per imparare a progettare agenti AI, workflow multi-agent, runtime controllati, artefatti verificabili e cicli di miglioramento basati su review e knowledge absorption.

Partiamo da concetti semplici, file Markdown e singoli agenti. Arriviamo gradualmente a una factory capace di creare, governare e migliorare agenti specializzati per progetti diversi.

Competenze chiave: prompt operativo, Agent Card, output contract, governance, Python minimo, API, review, memoria e orchestrazione multi-agent.
