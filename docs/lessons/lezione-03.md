# Lezione 3 - La differenza tra una Automazione e un Vero AI Agent

Questa lezione introduce la differenza tra software tradizionale, automazione, automazione con AI e veri AI Agent.

## Principi fondamentali

- Un AI Agent ha un obiettivo.
- Ragiona sulle azioni da compiere.
- Usa strumenti (tool).
- Osserva i risultati.
- Accumula esperienza.

## Regola architetturale

Gli agenti sono temporanei.
La conoscenza è permanente.

## Visione Agent Factory

Ricevere un progetto -> creare agenti specializzati -> farli collaborare -> validare i risultati -> riassorbire la conoscenza -> distruggere gli agenti temporanei.

## Concetti emersi

- Working Memory
- Episodic Memory
- Semantic Memory
- Knowledge Compiler
- Evolution Engine

Gli agenti non dovrebbero modificare direttamente la conoscenza permanente: producono esperienza che viene validata e trasformata in conoscenza riutilizzabile.
