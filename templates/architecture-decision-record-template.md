# Architecture Decision Record Template

Usare questo template per registrare una decisione architetturale presa da Architect Agent.

Un ADR deve spiegare non solo cosa si decide, ma anche perche', quali alternative sono state considerate e quando la decisione andra' rivalutata.

## Metadati

```text
Progetto: [Nome progetto]
ADR: [Numero o codice]
Titolo: [Decisione sintetica]
Versione: v0.1
Data: [YYYY-MM-DD]
Autore/Agente: Architect Agent
Stato: [Proposta / Accettata / Rifiutata / Superata / Da rivedere]
```
