# Agent Skill Template

Usare questo template per progettare una skill riutilizzabile dentro AgentFactory.

Una skill non e' un agente completo.

Una skill e' una procedura operativa che un agente puo' usare quando serve.

Stato: [Bozza / Validabile / Validata / Deprecata]
Proprietario: [Agente o umano responsabile]
Ultimo aggiornamento: [YYYY-MM-DD]
